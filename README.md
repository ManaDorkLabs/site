# Mana Dork Labs

Source for [manadorklabs.com](https://manadorklabs.com). A single self-contained static HTML page with no build step and no dependencies.

## Local preview

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Stack

Plain HTML and CSS. Type is [Space Mono](https://fonts.google.com/specimen/Space+Mono) and [Roboto Flex](https://fonts.google.com/specimen/Roboto+Flex), loaded from Google Fonts. Deployed on Vercel; response headers are configured in `vercel.json`.
